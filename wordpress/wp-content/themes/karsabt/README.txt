قالب اختصاصی کارثبت (Karsabt) - نسخه 1.0.0

نصب:
1. پوشه karsabt را در مسیر wp-content/themes قرار دهید.
2. از پیشخوان وردپرس > نمایش > پوسته‌ها، قالب را فعال کنید.
3. در نمایش > فهرست‌ها، منوی اصلی و در صورت نیاز منوی پایین صفحه را به جایگاه مربوط متصل کنید.
4. یک برگه را به‌عنوان صفحه نوشته‌ها و صفحه نخست را به‌عنوان صفحه ایستا تنظیم کنید؛ قالب front-page.php را برای صفحه اصلی به‌کار می‌برد.
5. برای نمایش فرم سفارش، افزونه Karsabt Core باید فعال باشد و شورت‌کد [karsabt_order_form] را فراهم کند.
6. برای طراحی صفحه اصلی و برگه‌ها با Elementor، برگه را با Elementor ویرایش و طرح خود را منتشر کنید؛ صفحه اصلی در حالت طراحی‌شده با Elementor محتوای صفحه‌ساز را نمایش می‌دهد.
7. برای سربرگ و پابرگ اختصاصی، از Theme Builder المنتور و شرط‌های نمایش استفاده کنید.
8. برای نمایش نوشته‌ها، نوشته‌های وردپرس را منتشر کنید.

امکانات:
- طراحی فارسی و راست‌چین و واکنش‌گرا با CSS مدرن، متغیرهای CSS، Grid، Flexbox، تایپوگرافی سیال و Container Queries
- پیکربندی طراحی سراسری وردپرس از طریق theme.json و هماهنگی رنگ‌ها و تایپوگرافی ویرایشگر بلوکی
- استایل اختصاصی ویرایشگر بلوکی با پشتیبانی RTL
- منوی موبایل با پشتیبانی صفحه‌کلید و دسترس‌پذیری پایه
- لوگوی سفارشی و فهرست‌های قابل مدیریت از پیشخوان
- تصویر شاخص و اندازه تصویر اختصاصی کارت‌ها
- قالب‌های صفحه، نوشته، جست‌وجو و خطای ۴۰۴
- بارگذاری فایل‌های CSS و JavaScript با نسخه مبتنی بر زمان تغییر برای جلوگیری از کش نسخه قدیمی
- سازگاری با Elementor برای ویرایش صفحه اصلی و برگه‌ها با عرض کامل
- پشتیبانی از قالب‌ساز Elementor برای جایگزینی سربرگ، پابرگ، نوشته تکی و آرشیو (در صورت استفاده از نسخه سازگار Elementor/Pro)

یادآوری:
- شماره تماس و اطلاعات ارتباطی باید پیش از بهره‌برداری نهایی در فایل‌های قالب/تنظیمات سایت جایگزین و تأیید شوند.
- قالب به‌تنهایی درگاه پرداخت یا پیامک ایجاد نمی‌کند؛ این قابلیت‌ها به افزونه و سرویس‌های متصل وابسته‌اند.
