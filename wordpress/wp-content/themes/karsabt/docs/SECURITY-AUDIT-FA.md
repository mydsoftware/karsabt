# گزارش ممیزی امنیتی قالب کارثبت

تاریخ: ۱۴۰۵/۰۸/۳۰  
شاخه: `main`

## دامنه بررسی

فایل‌های اصلی قالب، الگوهای خدمات، کارت‌های محتوا، جاوااسکریپت منوی موبایل، خروجی‌های متادیتا و JSON-LD، متاباکس پرسش‌های متداول و آزمون ایستای قالب بررسی شدند. افزونه **Karsabt Core** در این مرحله تغییر نکرده است.

## اصلاحات انجام‌شده

1. تمام خروجی‌های JSON-LD با پرچم‌های `JSON_HEX_TAG`، `JSON_HEX_AMP`، `JSON_HEX_APOS` و `JSON_HEX_QUOT` تولید می‌شوند تا داده‌های پویا نتوانند تگ اسکریپت را بشکنند.
2. تشخیص کلاس کمکی Rank Math به نام کامل صحیح `\RankMath\Helper` اصلاح شد تا در صورت فعال‌بودن این افزونه، قالب متادیتای تکراری تولید نکند.
3. هنگام ذخیره FAQ، درخواست‌های autosave و revision نادیده گرفته می‌شوند؛ بررسی nonce و سطح دسترسی نیز حفظ شده است.
4. آزمون ایستا برای کنترل این موارد امنیتی گسترش یافت.

## نکات مثبت مشاهده‌شده

- خروجی متون و ویژگی‌های HTML در الگوهای بررسی‌شده عمدتاً با توابع متناسب وردپرس مانند `esc_html`، `esc_attr`، `esc_url` و `esc_textarea` پاک‌سازی می‌شود.
- ورودی FAQ با `wp_unslash` و توابع پاک‌سازی متنی پردازش می‌شود.
- ذخیره FAQ به nonce معتبر و مجوز `edit_page` وابسته است.
- دسترسی مستقیم به فایل‌های PHP قالب با کنترل `ABSPATH` مسدود شده است.
- لینک‌های قابل تنظیم از `esc_url` در خروجی استفاده می‌کنند.

## موارد نیازمند بررسی در محیط واقعی

- نصب تمیز وردپرس و فعال‌سازی قالب با نسخه‌های پشتیبانی‌شده PHP و WordPress.
- بررسی خروجی نهایی HTML و JSON-LD در مرورگر، به‌ویژه با داده‌های فارسی، نقل‌قول و نویسه‌های ویژه.
- آزمون هم‌زمان Rank Math، Yoast، SEOPress و سایر افزونه‌های سئو برای جلوگیری از متادیتای تکراری.
- آزمون واقعی Elementor، Gutenberg، فرم سفارش و افزونه Karsabt Core.
- آزمون امنیتی فرم‌ها و endpointهای افزونه Karsabt Core خارج از دامنه این ممیزی قالب.
- اجرای اسکن دسترس‌پذیری، تست مرورگر و Lighthouse روی سایت نصب‌شده.

## محدودیت ممیزی

این گزارش ممیزی ایستا بر مبنای کد مخزن است و جایگزین آزمون نفوذ، بازبینی runtime، بررسی تنظیمات سرور یا ممیزی مستقل افزونه‌ها نیست. هیچ ادعایی درباره امنیت کامل سایت یا عملکرد هاست واقعی مطرح نمی‌شود.

## اجرای آزمون

از ریشه مخزن:

```bash
php tests/php/karsabt-theme-quality-test.php
```

گردش‌کار GitHub Actions نیز بررسی نگارش PHP، اعتبار `theme.json` و آزمون‌های ایستا را اجرا می‌کند.
