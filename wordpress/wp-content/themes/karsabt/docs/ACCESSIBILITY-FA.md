# ممیزی دسترس‌پذیری قالب کارثبت

این سند تغییرات پایه و موارد لازم برای آزمون نهایی قالب را ثبت می‌کند.

## اصلاحات اعمال‌شده
- حفظ پیوند پرش به محتوای اصلی در سربرگ با مقصد `#main-content`.
- نمایش نشانگر واضح تمرکز برای پیمایش با صفحه‌کلید.
- پشتیبانی از تنظیم سیستم‌عامل برای کاهش حرکت و انیمیشن.
- پشتیبانی بهتر از حالت کنتراست اجباری ویندوز.
- هماهنگ‌سازی وضعیت منوی موبایل هنگام عبور از نقطه شکست واکنش‌گرا.
- انتقال تمرکز به نخستین پیوند منو هنگام بازشدن منوی موبایل و بازگرداندن تمرکز به دکمه هنگام بستن با Escape.

## چک‌لیست آزمون دستی پیش از انتشار
- [ ] تمام صفحات فقط با کلیدهای Tab، Shift+Tab، Enter و Escape قابل استفاده باشند.
- [ ] ترتیب تمرکز با ترتیب بصری و معنایی صفحه هماهنگ باشد.
- [ ] در تمام صفحات، پیوند «رفتن به محتوای اصلی» قابل مشاهده و قابل استفاده باشد.
- [ ] منوی موبایل با صفحه‌کلید باز و بسته شود و وضعیت `aria-expanded` درست تغییر کند.
- [ ] عنوان و برچسب فیلدهای فرم سفارش برای فناوری‌های کمکی قابل تشخیص باشند.
- [ ] تصاویر محتوایی متن جایگزین معنادار داشته باشند؛ تصاویر تزئینی با متن جایگزین خالی ارائه شوند.
- [ ] کنتراست متن عادی حداقل ۴٫۵ به ۱ و متن بزرگ حداقل ۳ به ۱ باشد.
- [ ] صفحه با بزرگ‌نمایی ۲۰۰٪ و عرض ۳۲۰ پیکسل بدون پیمایش افقی غیرضروری کار کند.
- [ ] حالت کاهش حرکت و حالت کنتراست اجباری بررسی شود.
- [ ] با NVDA یا VoiceOver، عنوان‌ها، پیوندها، دکمه‌ها، فرم‌ها و پیام‌های وضعیت بررسی شوند.

## محدودیت اعتبارسنجی
این تغییرات به‌تنهایی گواه انطباق کامل با WCAG نیستند. آزمون دستی با صفحه‌خوان، بررسی کنتراست، صفحات واقعی و فرم افزونه Karsabt Core باید پیش از انتشار انجام شود. در این مرحله هیچ ادعایی درباره موفقیت آزمون Lighthouse یا آزمون صفحه‌خوان ثبت نمی‌شود.
