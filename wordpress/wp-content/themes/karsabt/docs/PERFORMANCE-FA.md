# بهینه‌سازی عملکرد قالب کارثبت

## بارگذاری فایل‌ها
- فایل‌های CSS و JavaScript با نسخه مبتنی بر `filemtime` بارگذاری می‌شوند تا پس از تغییر فایل، کش مرورگر نسخه قدیمی را استفاده نکند.
- اسکریپت اصلی قالب در فوتر بارگذاری می‌شود و در نسخه‌های سازگار وردپرس، راهبرد `defer` می‌گیرد. وردپرس ترتیب وابستگی‌ها را مدیریت می‌کند.
- برای سازگاری با حداقل نسخه اعلام‌شده قالب (وردپرس ۶.۲)، فراخوانی راهبرد defer با بررسی وجود تابع انجام می‌شود؛ در نسخه‌های قدیمی‌تر، اسکریپت همچنان در فوتر بارگذاری خواهد شد.

## تصاویر
- تصاویر شاخص کارت مقالات با اندازه اختصاصی `karsabt-card` (۶۴۰×۴۲۰) درخواست می‌شوند تا به‌جای فایل بزرگ‌تر، اندازه متناسب کارت دریافت شود.
- ویژگی‌های `loading="lazy"` و `decoding="async"` برای تصاویر کارت مقالات فعال هستند.
- ویژگی `sizes` به مرورگر کمک می‌کند از میان اندازه‌های تولیدشده وردپرس، فایل مناسب عرض نمایش را انتخاب کند.
- تصویر گرافیکی Hero صفحه اصلی با CSS ساخته شده و تصویر دانلودی نیست؛ بنابراین preload یا fetchpriority غیرضروری به آن اضافه نشده است.
- بارگذاری تنبل سراسری تصاویر دست‌کاری نشده تا تصویر اصلی و محتوای بالای صفحه ناخواسته دیر بارگذاری نشوند.

## بررسی پس از انتشار
1. کش افزونه، سرور و مرورگر را پاک کنید.
2. در ابزار PageSpeed Insights یا Lighthouse، صفحه اصلی و یک صفحه مقاله را جداگانه بررسی کنید.
3. در پنل Network مرورگر، کنترل کنید تصاویر کارت از اندازه مناسب و فایل‌های CSS/JS با نسخه جدید دریافت شوند.
4. پس از نصب وردپرس واقعی، رفتار منوی موبایل، Elementor و فرم سفارش را نیز بررسی کنید.

## نکته
بهینه‌سازی واقعی سرعت به تصاویر بارگذاری‌شده توسط مدیر سایت، کیفیت هاست، کش سرور، فونت‌ها و افزونه‌های فعال نیز وابسته است. این تغییرات بدون دست‌کاری افزونه Karsabt Core انجام شده‌اند.
