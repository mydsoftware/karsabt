# سئوی فنی قالب کارثبت

## متادیتا و شبکه‌های اجتماعی
- اگر Yoast SEO، Rank Math، SEOPress، The SEO Framework یا AIOSEO فعال باشد، خروجی متادیتای سئو و Schema خود قالب غیرفعال می‌شود تا تداخل و تکرار ایجاد نشود.
- در نبود افزونه سئو، توضیح متا از خلاصه برگه/نوشته و در صورت نبود آن از توضیحات سایت ساخته می‌شود.
- عنوان صفحه از سازوکار استاندارد عنوان وردپرس استفاده می‌کند.
- Open Graph و Twitter Card از عنوان، توضیح و تصویر شاخص ساخته می‌شوند؛ در نبود تصویر شاخص، لوگوی سایت استفاده می‌شود.
- canonical عمداً توسط قالب تولید نمی‌شود و باید به وردپرس یا افزونه سئو واگذار شود.

## داده ساختاریافته
- اطلاعات پایه سازمان از نام سایت، نشانی اصلی و لوگوی تنظیم‌شده در هویت سایت وردپرس می‌آید.
- آدرس فیزیکی، تلفن، مختصات و ساعات کاری درج نشده‌اند؛ تا زمانی که اطلاعات واقعی کسب‌وکار تأیید نشده‌اند، نباید داده ساختگی منتشر شود.
- BreadcrumbList برای صفحات داخلی، نوشته‌ها، دسته‌ها، جستجو و آرشیو تولید می‌شود.
- FAQPage فقط در صورت ثبت پرسش و پاسخ و در نبود افزونه سئو تولید می‌شود.

## مسیر راهنما
برای نمایش مسیر راهنما در هر برگه یا قالب Elementor، از شورت‌کد زیر استفاده کنید:

`[karsabt_breadcrumbs]`

برای هماهنگی ظاهری، کلاس اصلی خروجی `karsabt-breadcrumbs` است و می‌توان آن را در Elementor یا CSS سفارشی استایل‌دهی کرد.

## بررسی نهایی
پس از نصب روی هاست:
1. سورس صفحه را بررسی کنید و مطمئن شوید متای description و OG تکراری نیست.
2. اگر افزونه سئو نصب است، خروجی متادیتا و Schema آن تنها مرجع باشد.
3. داده‌های ساختاریافته را با ابزارهای اعتبارسنجی Schema بررسی کنید.
4. عنوان و توضیح صفحات خدمات را دستی بازبینی کنید؛ توضیح خودکار جای متن اختصاصی و باکیفیت را نمی‌گیرد.
