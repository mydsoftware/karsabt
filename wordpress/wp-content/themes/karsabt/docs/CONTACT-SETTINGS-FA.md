# تنظیم اطلاعات تماس قالب کارثبت

برای تنظیم اطلاعات واقعی سربرگ و پابرگ:
1. وارد پیشخوان وردپرس شوید.
2. به «نمایش ← سفارشی‌سازی» بروید.
3. بخش «اطلاعات تماس کارثبت» را باز کنید.
4. تلفن، ایمیل و نشانی یا محدوده فعالیت را وارد و منتشر کنید.

فیلدهای خالی نمایش داده نمی‌شوند؛ بنابراین قالب دیگر نشانی یا ایمیل ثابت و تأییدنشده منتشر نمی‌کند. تلفن به پیوند قابل لمس `tel:` و ایمیل به پیوند `mailto:` تبدیل می‌شود.

اگر از قالب‌ساز Elementor برای سربرگ یا پابرگ استفاده می‌کنید، اطلاعات این بخش به‌صورت خودکار داخل قالب Elementor قرار نمی‌گیرد؛ باید در طراحی Elementor از همین مقادیر استفاده یا آن‌ها را دستی وارد کنید.
