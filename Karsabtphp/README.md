# Karsabt PHP

نسخه مستقل PHP کارثبت با پایگاه داده MySQL.

## نسخه
V17 — MySQL

## فناوری‌ها
- PHP 8.2+
- MySQL / MariaDB
- PDO MySQL
- HTML5، CSS3 و JavaScript خالص

## نصب
1. پوشه پروژه را روی هاست cPanel بارگذاری کنید.
2. در MySQL Database Wizard یک دیتابیس و کاربر بسازید.
3. دسترسی کاربر را به دیتابیس اعطا کنید.
4. اطلاعات اتصال را مطابق راهنمای نصب پروژه تنظیم کنید.
5. راهنمای `INSTALL-FA.md` را دنبال کنید.

## نکته
این پوشه محل نگهداری نسخه مستقل PHP است و با قالب و افزونه وردپرس این مخزن ادغام نمی‌شود.
