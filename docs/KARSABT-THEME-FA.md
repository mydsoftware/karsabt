# راهنمای قالب کارثبت

## مسیر قالب
`wordpress/wp-content/themes/karsabt`

## امکانات
- صفحه اصلی فارسی و راست‌چین با معرفی خدمات، مقالات و بخش سفارش
- منوی اصلی قابل مدیریت از پیشخوان وردپرس
- منوی موبایل با کنترل وضعیت، بستن با کلید Escape و بستن با کلیک بیرون منو
- پشتیبانی از لوگوی سفارشی، تصویر شاخص و اندازه اختصاصی تصویر کارت
- الگوهای صفحه، نوشته، فهرست نوشته‌ها، بایگانی، جست‌وجو و خطای ۴۰۴
- پیوند پرش به محتوای اصلی، نشانگر فوکوس صفحه‌کلید و رعایت تنظیم کاهش حرکت
- بارگذاری CSS و JavaScript با نسخه مبتنی بر زمان آخرین تغییر فایل

## نصب و پیکربندی
1. پوشه `karsabt` را در `wp-content/themes/` قرار دهید.
2. قالب را از پیشخوان فعال کنید.
3. در نمایش ← فهرست‌ها، منوی اصلی را به جایگاه «منوی اصلی» متصل کنید.
4. در صورت نیاز منوی پایین صفحه را به جایگاه «منوی پایین صفحه» متصل کنید.
5. از بخش هویت سایت، لوگوی کارثبت را بارگذاری کنید.
6. صفحه نخست را در تنظیمات ← خواندن روی یک برگه ایستا قرار دهید.
7. برای فرم سفارش، افزونه Karsabt Core باید فعال باشد و شورت‌کد `[karsabt_order_form]` را ارائه کند.

## نکات پیکربندی پیش از بهره‌برداری
- ایمیل، شماره تماس، نشانی و اطلاعات پشتیبانی در هدر و فوتر باید با اطلاعات تأییدشده کسب‌وکار جایگزین شوند.
- صفحات خدمات باید از پیشخوان ایجاد و محتوای نهایی، قیمت‌ها، شرایط و مدارک لازم در آن‌ها درج شوند.
- نوشته‌های آموزشی باید با محتوای معتبر و به‌روز منتشر شوند.
- پیوندهای منو باید به برگه‌های واقعی سایت اشاره کنند.
- عنوان و توضیحات سئو، نقشه سایت و داده‌های ساختاریافته باید با افزونه سئو یا راهکار واحد سایت تنظیم شوند تا متاتگ تکراری تولید نشود.

## چک‌لیست آزمون روی هاست واقعی
- [ ] فعال‌سازی قالب روی نسخه پشتیبانی‌شده وردپرس و PHP
- [ ] بررسی صفحه اصلی در موبایل، تبلت و دسکتاپ
- [ ] بررسی منوی اصلی، منوی موبایل و منوی پایین صفحه
- [ ] بررسی لوگو، تصویر شاخص، فونت و بارگذاری فایل‌های استاتیک
- [ ] بررسی صفحات داخلی، نوشته‌ها، دسته‌بندی‌ها، جست‌وجو و ۴۰۴
- [ ] بررسی دسترس‌پذیری با صفحه‌کلید و نمایش فوکوس
- [ ] بررسی فرم سفارش پس از فعال‌سازی افزونه Karsabt Core
- [ ] بررسی پیوندها، canonical، عنوان صفحه و متاتگ‌ها
- [ ] بررسی خطاهای PHP و کنسول مرورگر

این چک‌لیست تا زمان اجرای آزمون روی هاست واقعی، تکمیل‌شده محسوب نمی‌شود.
