# راه‌اندازی Karsabt روی ویندوز و XAMPP

## پیش‌نیاز
- Windows 10/11
- XAMPP با Apache، MySQL/MariaDB و PHP سازگار با نسخه WordPress نصب‌شده
- WordPress از منبع رسمی

## نصب
1. کنترل‌پنل XAMPP را باز کنید و Apache و MySQL را Start کنید.
2. وارد `http://localhost/phpmyadmin` شوید.
3. دیتابیسی با نام `karsabt` و Collation برابر `utf8mb4_unicode_ci` بسازید.
4. WordPress را در مسیر `C:\\xampp\\htdocs\\karsabt` استخراج کنید.
5. آدرس `http://localhost/karsabt` را باز کنید و نصب را با این مشخصات انجام دهید:
   - نام دیتابیس: `karsabt`
   - نام کاربری: `root`
   - رمز: خالی (فقط برای محیط محلی پیش‌فرض XAMPP؛ برای محیط قابل دسترس از شبکه مناسب نیست)
   - میزبان: `localhost`
   - پیشوند جدول: `wp_`
6. پوشه `wordpress/wp-content/themes/karsabt` از مخزن را به مسیر `C:\\xampp\\htdocs\\karsabt\\wp-content\\themes\\karsabt` کپی کنید.
7. در پیشخوان به «نمایش ← پوسته‌ها» بروید و Karsabt را فعال کنید.
8. در «نمایش ← فهرست‌ها» فهرست بسازید و محل «منوی اصلی» را انتخاب کنید.

## تنظیم صفحه اصلی
قالب از فایل `front-page.php` برای صفحه اصلی استفاده می‌کند. نوشته‌های منتشرشده در بخش مقالات به‌صورت خودکار نمایش داده می‌شوند. اگر نوشته‌ای وجود نداشته باشد، کارت‌های راهنمای اولیه دیده می‌شوند.

## نکات
- ایمیل `info@karsabt.ir` در نسخه پایه صرفاً مقدار پیش‌فرض است؛ قبل از انتشار باید تأیید/جایگزین شود.
- شماره تماس عمداً جای‌نگهدار است.
- در نسخه فعلی فرم سفارش و پرداخت آنلاین پیاده‌سازی نشده‌اند.
- دیتابیس، فایل‌های `wp-config.php`، آپلودها و مدارک مشتریان را در Git قرار ندهید.
- برای انتقال به هاست واقعی، از خروجی پشتیبان دیتابیس و فایل‌ها استفاده و آدرس‌ها را با ابزار مهاجرت WordPress اصلاح کنید.
