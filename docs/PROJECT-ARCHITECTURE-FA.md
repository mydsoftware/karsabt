# معماری فنی پروژه کارثبت

## اصول
- WordPress هسته مدیریت محتوا و کاربران است.
- قالب `Karsabt` فقط مسئول نمایش، چیدمان و تجربه کاربری است.
- منطق کسب‌وکار باید در افزونه مستقل `Karsabt Core` باشد، نه در قالب.
- وابستگی اجباری به Elementor یا صفحه‌ساز مشابه ایجاد نمی‌شود.
- همه صفحات باید فارسی، RTL، واکنش‌گرا و قابل استفاده با موبایل باشند.

## مسیرهای اصلی محصول
- صفحه اصلی
- ثبت شرکت و تغییرات
- ثبت برند و علامت تجاری
- جواز کسب و پروانه صنفی
- مجوز مشاغل خانگی
- کافی‌نت آنلاین
- خدمات اداری و اینترنتی
- وبلاگ و راهنماها
- تماس و درباره ما

## وضعیت ماژول‌های Karsabt Core
- **پیاده‌سازی اولیه:** نوع محتوای خصوصی درخواست‌ها، فرم عمومی با کد کوتاه، اعتبارسنجی و nonce سمت سرور، ثبت در پایگاه داده و مدیریت وضعیت در پیشخوان.
- **در حال توسعه:** پرونده مشتری، تاریخچه فعالیت و شناسه پیگیری قابل ارائه به مشتری.
- **برنامه بعدی:** بارگذاری امن مدارک با کنترل دسترسی و محدودیت نوع/حجم فایل، اعلان پیامکی، پرداخت با تأیید سمت سرور و گزارش درآمد.

افزونه در مسیر `wordpress/wp-content/plugins/karsabt-core` قرار دارد. راهنمای نصب در `docs/KARSABT-CORE-FA.md` است.

## امنیت و حریم خصوصی
- اطلاعات هویتی و مدارک مشتری نباید در مخزن Git یا مسیر عمومی وب ذخیره شوند.
- دسترسی به پرونده‌ها باید بر اساس نقش و مالکیت کنترل شود.
- nonce، اعتبارسنجی سمت سرور، پاک‌سازی ورودی و escape خروجی الزامی است.
- هیچ درگاه، پیامک یا API key نباید در کد یا تاریخچه Git ثبت شود.
- فرم نباید موفقیت را اعلام کند مگر اینکه داده واقعاً در مقصد امن ذخیره شده باشد.

## انتشار
توسعه روی لوکال XAMPP انجام می‌شود. پس از تست، نسخه قابل انتشار روی هاست سازگار با WordPress مستقر می‌شود. تنظیمات محیطی و اسرار نباید همراه کد commit شوند.
