# کارثبت | Karsabt.ir

مخزن اصلی و مرجع توسعه وب‌سایت کارثبت.

## وضعیت پروژه
- محیط توسعه فعلی: WordPress روی Windows + XAMPP
- دامنه انتشار: https://karsabt.ir
- شاخه توسعه فعال: `feature/wordpress-theme`
- شاخه انتشار: `main`
- قالب اختصاصی: `wordpress/wp-content/themes/karsabt`

## شروع توسعه محلی
راهنمای کامل نصب در [docs/LOCAL-SETUP-FA.md](docs/LOCAL-SETUP-FA.md) قرار دارد.

خلاصه:
1. XAMPP را اجرا کنید و Apache و MySQL را روشن کنید.
2. وردپرس را در `C:\\xampp\\htdocs\\karsabt` نصب کنید.
3. پوشه قالب این مخزن را در `wp-content/themes/karsabt` قرار دهید.
4. قالب Karsabt را از پیشخوان فعال کنید.

## ساختار
- `wordpress/wp-content/themes/karsabt`: قالب اختصاصی فارسی و واکنش‌گرا
- `docs/`: راهنماها، تصمیم‌های فنی و نقشه راه
- `assets/`: فایل‌های مشترک و منابع طراحی

## قانون هماهنگی توسعه
این مخزن تنها مرجع رسمی کد و مستندات پروژه است. هر قابلیت جدید باید:
1. در شاخه‌ای بر پایه آخرین `feature/wordpress-theme` توسعه یابد.
2. در همین مخزن ثبت شود؛ فایل‌های محلی و ZIP فقط خروجی قابل نصب هستند، نه مرجع اصلی.
3. همراه با مستندات فارسی، تست و توضیح تغییرات باشد.
4. از ارسال فایل‌های محرمانه، رمزها، بکاپ دیتابیس و مدارک کاربران به GitHub خودداری کند.

تا زمان آماده‌شدن نسخه انتشار، تغییرات روی شاخه توسعه انجام می‌شوند و پس از بررسی از طریق Pull Request به `main` می‌روند.
