# کارثبت | Karsabt.ir

سامانه آنلاین خدمات ثبت شرکت، ثبت برند، جواز کسب، مجوز مشاغل خانگی، کافی‌نت آنلاین و خدمات اداری.

**بازار آغازین:** دزفول  
**شاخه مرجع توسعه و انتشار فعلی:** `main`

## وضعیت فعلی
- قالب اختصاصی WordPress فارسی و RTL
- افزونه اختصاصی Karsabt Core نسخه 0.30.0
- مدیریت درخواست، کد پیگیری، حساب مشتری و پنل‌های مشتری/کارشناس
- پرونده، پیام، مدارک خصوصی، گردش کار، چک‌لیست، مهلت و زمان‌سنج
- امکانات مالی اولیه، فاکتور و ثبت پرداخت دستی
- گزارش‌های مدیریت و عملیات

## نصب قالب و افزونه
- قالب: `wordpress/wp-content/themes/karsabt`
- افزونه: `wordpress/wp-content/plugins/karsabt-core`

این مخزن حاوی بسته WordPress کامل نیست؛ قالب و افزونه را در نصب موجود WordPress قرار دهید.

## امنیت
- اطلاعات کاربران و مدارک خصوصی را داخل Git commit نکنید.
- کلیدها، رمزها، بکاپ پایگاه داده و فایل‌های مشتری نباید در مخزن قرار گیرند.
- مدارک باید در مسیر خصوصی خارج از web root ذخیره شوند.
- تنظیم HTTPS، پشتیبان‌گیری و کنترل دسترسی پیش از بهره‌برداری الزامی است.
